# 前端 i18n（中文原文作 key，新增 en-US）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 本仓库约定不使用子代理，全部内联执行。

**Goal:** 将 `src/` 下所有 `.ts` / `.mts` / `.vue` 中硬编码的中文 UI 文案迁移到 vue-i18n，新增 en-US 语言；语言完全由前端控制，localStorage 持久化。

**Architecture:** vue-i18n v11（`legacy: false`）全局单实例。**中文原文直接作 message key**：en-US 是唯一需要人工维护的翻译文件；zh-CN 消息由 en-US 的 key 恒等映射自动生成（`key === value`），零维护。所有调用点统一 `import { t } from ".../i18n"`，模板、组件脚本、stores、utils 一律同一形态。key 缺失时 vue-i18n 返回 key 本身（中文原文），天然构成回退。

**Tech Stack:** vue-i18n ^11（当前 latest 11.4.18）；现有 Vite 8 + vue-tsc + vitest（node 环境）。

## 已确认的需求决策（2026-11-04 与用户确认）

1. 只新增 en-US 一种语言
2. Lua/脚本默认模板内容**不翻译**（是代码内容不是 UI 文案）；范围仅 `.ts` / `.mts` / `.vue`
3. 后端不感知语言，全部由前端控制；后端原始错误文案原样透传
4. landing 页不做浏览器语言自动探测，跟随全局设置
5. 一次性全量替换（不分子阶段上线）

## 范围

**内**：`src/**/*.ts`、`src/**/*.mts`（测试）、`src/**/*.vue` 中用户可见的中文文案（模板文本节点、属性绑定、字符串字面量、toast/确认框/错误前缀）。

**外**（明确不做）：
- 代码注释（约 254 行纯注释保持中文，不迁移）
- `src/**/*.html` 静态中文（`index.html` / `session.html` / `about-preview.html` 标题）
- Lua 脚本默认模板（`RedactionManagerWindow.vue` 的 `defaultSource`、skill 安装的脚本内容）
- 持久化数据 / 默认值类字符串（分享 `display_name` 等存进后端的数据，见「不翻译判定规则」）
- 后端 Rust 错误文案（前端 `reportError(error, "中文前缀")` 中只迁移中文前缀，`error` 原样透传）
- `skills/proxycrab/` 文档（已核查：无 UI 文案耦合，不涉及管理 API / 同步逻辑变更，无需更新）

## 核心设计：中文原文作 key

- **零命名成本**：约 1300+ 条文案不需要发明 key 名
- **只维护一个翻译文件**：en-US；zh-CN 由恒等映射派生
- **代码可读性不变**：中文开发者直接看到中文
- **自动去重**：相同中文（"刷新"、"取消"…）跨 107 文件自动收敛为一条 en 条目
- **缺失翻译优雅回退**：返回 key（中文），不显示乱码 key；dev 模式 console 有 missing 警告

已知约束：
- key 中含 ASCII `.` 会被 vue-i18n 当作嵌套路径分隔符。已扫描现有文案：**0 条含 `.`**。后续新增文案若含英文句点需用中文句号「。」或后续引入 `messageResolver`
- en-US 的**值**中字面 `@` / `|` / `{` / `}` 是 vue-i18n 语法字符，需写成 `{'@'}` 转义。现有中文文案 0 条含这些字符；插值占位 `{n}` 为有意语法
- 改中文文案 = 改 key，需同步所有引用处 + en 条目（文案极少变更，可接受）

## 替换规则手册（所有批次共用）

### R1 模板文本节点

```vue
<!-- 前 -->
<span>时间</span>
<!-- 后 -->
<span>{{ t("时间") }}</span>
```

### R2 静态属性 → 绑定

```vue
<!-- 前 -->
<button class="btn icon" title="刷新">
<!-- 后 -->
<button class="btn icon" :title="t('刷新')">
```

`aria-label`、`placeholder` 同理。

### R3 script 中的字符串字面量

```ts
// 前
appStore.toast("记录已删除", "success");
reportError(error, "获取透明转发记录失败");
// 后
appStore.toast(t("记录已删除"), "success");
reportError(error, t("获取透明转发记录失败"));
```

### R4 模板字面量插值 → 命名参数

```ts
// 前
appStore.toast(`已清空 ${deleted} 条记录`, "success");
// 后
appStore.toast(t("已清空 {n} 条记录", { n: deleted }), "success");
```

### R5 复数（仅 en 侧需要）

en 值用 `|` 分隔复数形式，调用传数字（vue-i18n 自动选择 + 提供默认 `{n}`）：

```ts
t("{n} 分钟前", minutes); // en: "{n} minute ago | {n} minutes ago"；zh 恒等值无 | 不受影响
```

判定规则：插值参数为数量且英文有单复数差异的必须写成 R5；其余用 R4。

### R6 「值即逻辑」的表（LEVELS / 分段控件）

内部值改语言无关，展示层翻译：

```ts
// 前（SystemLogsWindow.vue）
const LEVELS = ["全部", "ERROR", "WARN", "INFO", "DEBUG"] as const;
const levelFilter = ref<(typeof LEVELS)[number]>("全部");
const filtered = computed(() => levelFilter.value === "全部" || ...);
// 后
const LEVELS = ["all", "ERROR", "WARN", "INFO", "DEBUG"] as const;
const levelFilter = ref<(typeof LEVELS)[number]>("all");
const filtered = computed(() => levelFilter.value === "all" || ...);
// 模板展示：{{ l === "all" ? t("全部") : l }}
```

### R7 不翻译判定（保持原样）

- Lua/脚本源码模板、`#display_name` 注释内容
- 存入后端的持久化数据 / 默认值（如分享 `display_name` 的用户数据、脚本名）
- `error` 对象透传的后端原始消息（只翻译中文前缀）
- 注释

### R8 窗口标题（launcher.ts）

`windowsStore.open(..., { title: t("发送请求") })` — 打开时快照翻译。已打开窗口在语言切换后不重译（已知限制，可接受）。对应测试断言改为 `t("发送请求")`。

- [ ] **Step 4: 实现** `src/i18n/index.ts`

```ts
import { createI18n } from "vue-i18n";
import enUS from "./locales/en-US";

const STORAGE_KEY = "proxycrab.locale";

export type AppLocale = "zh-CN" | "en-US";

/**
 * 中文原文即 key：en-US 是唯一人工维护的翻译表；
 * zh-CN 由 en-US 的 key 恒等生成，无需单独维护。
 */
const zhCN: Record<string, string> = Object.fromEntries(
  Object.keys(enUS).map((key) => [key, key]),
);

function initialLocale(): AppLocale {
  if (typeof localStorage !== "undefined") {
    const saved = localStorage.getItem(STORAGE_KEY);
    if (saved === "zh-CN" || saved === "en-US") return saved;
  }
  if (typeof navigator !== "undefined" && !navigator.language.toLowerCase().startsWith("zh")) {
    return "en-US";
  }
  return "zh-CN";
}

export const i18n = createI18n({
  legacy: false,
  locale: initialLocale(),
  fallbackLocale: "zh-CN",
  messages: { "zh-CN": zhCN, "en-US": enUS },
});

/** 模板 / 组件脚本 / stores / utils 统一从本模块导入 t。 */
export const t = i18n.global.t;

export function setLocale(locale: AppLocale): void {
  i18n.global.locale.value = locale;
  if (typeof localStorage !== "undefined") localStorage.setItem(STORAGE_KEY, locale);
  if (typeof document !== "undefined") document.documentElement.lang = locale;
}
```

```ts
import { t } from "../i18n";

/** Epoch-millis → short relative time. */
export function formatRelativeTime(epochMs: number): string {
  const seconds = Math.floor((Date.now() - epochMs) / 1000);
  const minutes = Math.floor(seconds / 60);
  const hours = Math.floor(minutes / 60);
  const days = Math.floor(hours / 24);
  if (seconds < 60) return t("刚刚");
  if (minutes < 60) return t("{n} 分钟前", minutes);
  if (hours < 24) return t("{n} 小时前", hours);
  return t("{n} 天前", days);
}
```

## Task 9: 残留检查脚本 + 终验

- [ ] **Step 1: 写检查脚本**（行级启发式：与摸底脚本同规则——字符串字面量/模板文本含中文即 fail，注释行跳过）

```js
// scripts/check-i18n.mjs — 校验 src 下 .ts/.mts/.vue 无硬编码中文 UI 文案
// 跳过：注释行、src/i18n/locales/**、.html、白名单文件
import { readdirSync, readFileSync, statSync } from "node:fs";
import { join } from "node:path";

const ALLOW_FILES = new Set(["src/i18n/locales/en-US/index.ts"]);
const ALLOW_SUBSTRINGS = []; // 如 Lua 模板等需要豁免的片段
const CN = /[\u4e00-\u9fff]/;
const QUOTED = /['"`][^'"`]*[\u4e00-\u9fff][^'"`]*['"`]/;

function walk(dir, out = []) {
  for (const name of readdirSync(dir)) {
    const p = join(dir, name);
    if (statSync(p).isDirectory()) {
      if (name === "locales" && dir.endsWith("i18n")) continue;
      walk(p, out);
    } else if (/\.(ts|mts|vue)$/.test(name)) out.push(p);
  }
  return out;
}

let failures = 0;
for (const path of walk("src")) {
  if (ALLOW_FILES.has(path)) continue;
  const inVueTemplate = path.endsWith(".vue");
  let templateDepth = 0;
  const lines = readFileSync(path, "utf8").split("\n");
  lines.forEach((line, i) => {
    const s = line.trim();
    if (/<template[\s>]/.test(line)) templateDepth++;
    if (/<\/template>/.test(line)) templateDepth--;
    if (!CN.test(s)) return;
    const isComment =
      s.startsWith("//") || s.startsWith("*") || s.startsWith("/*") || s.startsWith("<!--");
    const hasLiteral = QUOTED.test(line) || (inVueTemplate && templateDepth > 0 && !isComment);
    if (!hasLiteral) return;
    if (ALLOW_SUBSTRINGS.some((frag) => line.includes(frag))) return;
    console.error(`${path}:${i + 1}: ${s}`);
    failures++;
  });
}
process.exit(failures ? 1 : 0);
```
